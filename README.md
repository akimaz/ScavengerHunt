# Project 1 - Photo Scavenger Hunt

Submitted by: **Angelina Kimaz**

**Photo Scavenger Hunt** is an app that allows users to complete scavenger hunt tasks by attaching photos. Users can select a task, attach a photo, view where the photo was taken on a map, and see when a task has been completed.

Time spent: **5 hours** spent in total

## Required Features

The following **required** functionality is completed:

- [x] App displays list of hard-coded tasks
- [x] When a task is tapped it navigates the user to a task detail view
- [x] When user adds photo to complete the task, it marks the task as complete
- [x] When adding photo of task, the location is added
- [x] User returns to home page (list of tasks) and the status of the task is updated to complete

The following **optional** features are implemented:

- [ ] User can launch camera to snap a picture

The following **additional** features are implemented:

- [x] Added a custom app icon
- [x] Added visual indicators to show completed and incomplete tasks
- [x] Added a map marker showing the location of the selected photo
